# collaboration-tools

INNODIGM 팀의 협업 도구 구성과 AI 어시스턴트 연동 설정을 정리한 저장소입니다.

전자결재시스템 프로젝트(8명 규모)를 운영하며 구축한 **Jira + Confluence + Slack + Google Drive** 협업 환경과, 해당 도구들을 Claude Code(CLI) 기반 AI 워크플로와 연결하기 위한 **MCP 서버 설정**을 문서로 남깁니다.

## 문서

| 파일 | 내용 |
|---|---|
| [`collaboration-tools.html`](./collaboration-tools.html) | 협업 도구 구성 가이드 (Jira/Confluence/Slack/Drive 역할·무료 플랜 조건·기본 세팅) |
| [`claude-code-mcp-setup.md`](./claude-code-mcp-setup.md) | Claude Code MCP 설치/인증 가이드 (Atlassian OAuth, Slack Bot, GitLab, Fetch 등 8개 서버) |

## 대상 독자

- 소규모 팀(10명 이하)에서 무료 협업 도구로 업무 환경을 꾸리려는 팀 리드
- Claude Code나 Claude Desktop에 사내 도구를 MCP로 연동하려는 개발자
