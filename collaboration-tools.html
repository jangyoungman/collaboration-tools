3-2. 워크플로우

상태설명
TO DO할 일 (아직 시작하지 않음)

버그 (Bug)결함 보고로그인 실패 오류

  1. 상단 + 만들기 클릭

  3. 제목, 설명, 담당자, 우선순위, 기한 입력
  4. 만들기 클릭

7. 팀원 초대 방법

Jira + Confluence (Atlassian)

  1. https://admin.atlassian.com 접속
  2. 사용자 → 사용자 초대
  3. 이메일 입력, 역할: Basic (일반 팀원)

Slack

  1. Slack 워크스페이스에서 별도로 초대
  2. 워크스페이스 이름 클릭 → 사람 초대

8. API 관리 (관리자용)

Confluence 페이지 생성/수정/첨부파일 삭제 등을 API로 처리할 수 있습니다.

항목값
인증 방식Basic Auth (이메일 + API 토큰)
API 토큰 관리Atlassian API 토큰 관리
Confluence APIhttps://innodigm.atlassian.net/wiki/api/v2/
Jira APIhttps://innodigm.atlassian.net/rest/api/3/

자주 사용하는 API

# 페이지 목록 조회
curl -u "이메일:API토큰" \
  "https://innodigm.atlassian.net/wiki/api/v2/spaces/229379/pages"

# 페이지 생성
curl -u "이메일:API토큰" -X POST \
  "https://innodigm.atlassian.net/wiki/api/v2/pages" \
  -H "Content-Type: application/json" \
  -d '{"spaceId":"229379","title":"제목","body":{"representation":"storage","value":"내용"}}'

# 첨부파일 삭제
curl -u "이메일:API토큰" -X DELETE \
  "https://innodigm.atlassian.net/wiki/api/v2/attachments/첨부파일ID"

9. 전체 업무 흐름

1. Confluence에 스펙 문서 작성 │ 2. Jira에 이슈 생성 (담당자, 기한 배정) │ 3. 담당자가 Jira 이슈를 IN PROGRESS로 이동 → Slack 자동 알림 │ 4. GitLab에 코드 Push → Slack 자동 알림 │ 5. 코드 리뷰 → Jira IN REVIEW │ 6. 완료 → Jira DONE → Slack 자동 알림 │ 7. 주간보고에 진행 상황 정리 (Confluence)
